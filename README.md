# Lamp
Designing an open source lamp.
Based on ESP32-C6 for ZigBee and HomeAssistant. 

## Design Goals
- Dimmable LED illumination
- ZigBee integration
- Control with HomeAssistant
- Battery + USB PD Powered
- Headroom for sensors
- 3D-printable body and lamp shade

## Used ICs
- ESP32-C6-MINI-1
- TPS25730D

## Battery Considerations
- 1S 21700
